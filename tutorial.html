Was ist SiPy?

SiPy ist eine einfache Programmiersprache für kleine Programme direkt im Browser. Der Editor kompiliert Code in schnelle Statements, führt sie aus und zeigt Output, Warnungen und Speicherzustand an.

Variablen, Konstanten und Kommentare

Normale Variablen werden mit = gespeichert. := schützt Werte vor späterer Neuzuweisung.

/* mehrzeiliger
Kommentar */
name := string("SiPy")
version = floater(2.0)
aktiv = boolean(True)
print(name)

Strings und Inline-Math

Strings können Python-nahe f-Strings nutzen. calc() berechnet kurze Rechenausdrücke.

a = integer(10)
b = integer(5)
print(f"Summe: {a.add(b)}")
print(calc("2 + 3 * 4"))
print(f"Name: {name}")

For, Switch und Try/Catch

Blöcke werden wie in Python mit Doppelpunkt und Einrückung geschrieben. for in range(), match/case und try/except sind eingebaut.

for i in range(0, 3):
    print(f"Index {i}")

match integer(2).value:
    case 1:
        print("eins")
        break
    case 2:
        print("zwei")
        break
    default:
        print("anderer Wert")

try:
    x := integer(1)
    x = integer(2)
except error:
    print(f"Gefangen: {error.message}")

Ein break innerhalb einer verschachtelten Schleife oder eines if/elif beendet nur diese Schleife bzw. Bedingung — nicht automatisch den umgebenden case-Block. Der Rest des case-Codes danach wird ganz normal weiter ausgeführt.

Tuple, Set, Queue, Stack und Enum

SiPy enthält unveränderliche Tupel, eindeutige Sets, FIFO-Queues, LIFO-Stacks und einfache Enums.

paar = tuple("x", 10)
werte = set("a", "b", "a")
aufgaben = queue()
stapel = stack()
Status = enumType("Status", ["Offen", "Fertig"])

aufgaben.enqueue("bauen")
stapel.push("oben")
print(paar)
print(werte)
print(aufgaben.dequeue())
print(stapel.pop())
print(Status.Fertig)

Generics, Interfaces, Bitfields und mehr

Für größere Programme bietet SiPy generische Typen, Interfaces, Bitfields, Casts, statische Klassen und Attribute-Annotationen.

generic Box[T]
interface Named(name)
Flags = bitfield("Flags", ["Read", "Write"])
UserType = Box.of("User")

@tracked("demo")
user = { name: "Ada" }

limit := cast(4, "integer")
rechte = Flags.value("Read", "Write")

print(implementsInterface(user, Named))
print(UserType)
print(rechte)

Asynchrone Abläufe und Coroutinen laufen über await und das concurrency-Modul:

import concurrency as go
await go.sleep(200)
print("fertig gewartet")

Debugging

Klicke links auf eine Zeilennummer, um einen Breakpoint zu setzen. Step führt ein Statement aus und der Memory-Inspector zeigt Variablen an.

a = integer(1)
breakpoint()
a = a.add(2)
print(a)

Oberhalb des Editors lassen sich Timeout (in Millisekunden) und Memory-Cap (maximale Anzahl gleichzeitiger Variablen) konfigurieren. Beim schrittweisen Debuggen zählt der Timeout nur die tatsächliche Ausführungszeit eines Schritts — Pausen zwischen Klicks auf Step lösen keinen Timeout-Fehler mehr aus.

Unter dem Memory-Inspector zeigt Variablen-Tracking jede Zuweisung aus dem Quellcode mit Zeilennummer an, damit nachvollziehbar bleibt, wo eine Variable gesetzt wurde.

Module

Die Module math, strings, collections, random, time, types und concurrency sind direkt verfügbar. Mit import ... as ... lässt sich ein Modul unter einem eigenen Namen einbinden, ohne bestehende Variablen zu überschreiben.

print(math.pi)
print(math.sqrt(16))
print(strings.upper("hallo"))
print(random.int(1, 6))
import math as m
print(m.sqrt(9))

Komplettes Beispiel

Dieses Beispiel nutzt Konstanten, For-Loop, Queue, Switch, String-Interpolation und Fehlerbehandlung.

limit := integer(3)
jobs = queue()

for i in range(0, limit.value):
    jobs.enqueue(f"Job {i}")

try:
    match jobs.size():
        case 3:
            print(f"Bereit: {jobs.size()} Jobs")
            break
        default:
            print("Andere Anzahl")
except error:
    print(f"Fehler: {error.message}")
